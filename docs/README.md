# Neverlur design notes

Wire-format design notes and other long-form documentation that the
Neverlur constitution Quality Gates require before code review begins.

The PQ-migration design notes (`wire-signed-config-v2.md`,
`wire-introduction-v2.md`, `wire-edtls-cert-v2.md`) are produced as
part of the work tracked under `specs/001-pq-hybrid-crypto/`. Until
those notes land, the protocol-level (US1/US2) work in
`specs/001-pq-hybrid-crypto/tasks.md` is gated on writing them first
(see tasks T063–T065).
